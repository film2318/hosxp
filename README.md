## Overview

A collection of 8 SQL queries developed to analyze a legacy HOSxP database containing 400K+ patient records across 50+ tables without an ER diagram, within a client–server architecture using relational database management systems (RDBMS).

## How to Use

1. Open the `.sql` file for the query you need.
2. Review the query and adjust table names or conditions if necessary.
3. press `F9` to run the query

## Tech Stack

* **Language:** SQL
* **Database:** MySQL
