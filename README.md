## Overview

Reverse-engineered HOSxP database schema using SQL DESCRIBE queries, analyzing 15+ OPD tables and 1M+ patient records without a data dictionary, saving THB 300,000 in training costs.

## How to Use

### SQL
1. Open the `.sql` file for the query you need.
2. Review and adjust table names or conditions as needed.
3. Execute the query in your SQL editor.

### Python
1. Install dependencies: `pip install pandas sqlalchemy pymysql tabulate`
2. Configure your MySQL connection.
3. Run `python mysql_connector.py` to extract and display data.
